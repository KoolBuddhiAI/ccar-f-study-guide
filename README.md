## Exam at a glance

- Code **CCAR-F** · $125 USD · 60 items / 120 minutes
- Exam structure: **4 scenarios drawn from a bank of 6** · multiple-choice **and** multiple-response
- Pass mark: scaled **720 / 1000** · valid 12 months · score report includes percent-correct by domain
- Proctored via Pearson VUE (online or test center)
- Official prep: Anthropic Partner Academy; practice: claudecertifiedarchitects.com, certsafari.com

Exam facts and scenarios come from the official **Exam Guide v1.0** (effective July 2026). Practice cases P1–P6 are original material, not endorsed by Anthropic.
