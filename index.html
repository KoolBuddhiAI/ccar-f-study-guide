1 · Agentic Architecture & Orchestration 27%

The agentic loop (stop_reason lifecycle), tested anti-patterns, coordinator–subagent hub-and-spoke, subagent context mechanics, programmatic enforcement vs prompt guidance, Agent SDK hooks. Deep dive →

Takeaway: loop on tool_use, stop on end_turn — never on words or counters. Gates belong in code; hints belong in prompts.

2 · Claude Code Config & Workflows 20%

CLAUDE.md hierarchy and scoping, @import and rules directories, slash commands, SKILL.md frontmatter (context: fork, allowed-tools), path-scoped rules, plan mode vs direct execution, iterative refinement, CI/CD integration. Deep dive →

Takeaway: configuration is layered by scope; skills are procedures with triggers, not always-loaded documents.

3 · Tool Design & MCP Integration 18%

Descriptions as the selection mechanism, tool splitting/renaming, structured error responses (errorCategory, isRetryable, access-failure vs empty-result), tool distribution and tool_choice modes, MCP server scoping and resources, built-in tools (Grep/Glob/Read/Write/Edit). Deep dive →

Takeaway: a tool's job on failure isn't to hide the error — it's to report it usefully so the agent can choose the next move.

4 · Prompt Engineering & Structured Output 20%

Categorical criteria vs "be conservative", few-shot for ambiguous cases, JSON schemas via tool use (strict ≠ semantically valid), retry-with-error-feedback, the Message Batches API (50% cost, 24h window, no mid-request tools), independent multi-instance review. Deep dive →

Takeaway: criteria not moods; examples not adjectives; schemas not prose; retries only when the information exists.

5 · Context Management & Reliability 15%

Case-facts blocks vs summarized history, lost-in-the-middle, trimming tool outputs, escalation triggers (and non-triggers), structured error propagation, scratchpads and crash-recovery state for codebase exploration. Deep dive →

Takeaway: context is a budget and a liability — facts at the edges, numbers verbatim, never trust a summary of something you can check.
